Started

Template d'un project simple en HTML, CSS {tailwind}, TypeScript ;

Étapes à suivre pour lancer le projet :

  • Changer le nom par défaut du projet "poutpout" en faisant une recherche globale sur votre éditeur de code et en le remplacant par le nom de votre projet.

  • Lancer les commandes npm run tailwind pour démarer tailwind et gulp pour lancer le serveur.

  • Vous êtes prêt à coder

Configuration de base :

  • - Nom de l'application angular : ng-app="poutpout"
  • - Nom du controller angular : ng-controller="ProjectBackController"
